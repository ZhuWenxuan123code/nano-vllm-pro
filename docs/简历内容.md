# nano-vLLM 推理算子融合与性能优化

技术栈：Python、PyTorch、Triton、CUDA Graph、Nsight Systems

- 基于 nano-vLLM 实现 Decode 阶段 Q/K RMSNorm、RoPE 与 Paged KV Cache 写入的 Triton 融合 kernel，支持 GQA、FP16/BF16 与 Graph padding；B=64、BF16 下单层链路 kernel 从 5 个减为 1 个，延迟下降 **73.5%**。
- 以现有 `torch.compile` 路径为基线，在 RTX 3090、Qwen3-0.6B、CUDA Graph 配置下各重复 5 次，Decode-heavy 端到端吞吐中位数提升 **2.17%**，Balanced 提升 **0.97%**；Nsight 确认完整模型 Decode kernel 执行次数减少 **25.7%**。
- 实现可切换的 Triton RMSNorm / Add-RMSNorm，支持 FP32 累加与非连续输入；完成数值、KV Cache、模型 logits 对照及 CUDA Graph 重放验证，27 项回归测试通过，并完成 TP=2 Eager 冒烟测试。
- 扩展 benchmark 的 batch、序列长度、Eager/CUDA Graph 与 TP 配置，固定 seed 并预热；结合 `torch.profiler`、Nsight Systems 分析 Prefill/Decode，自动生成吞吐、TTFT/TPOT 与多轮 A/B 对比报告。
